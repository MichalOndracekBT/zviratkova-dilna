# Zvířátková dílna

Hra pro předškoláky na iPhone: jednorožci a třpytky, puzzle se zvířátky, omalovánky, učení čísel 1–10 a česká abeceda.

Hrát: https://michalondracekbt.github.io/zviratkova-dilna/

Na iPhonu otevři odkaz v Safari → Sdílet → Přidat na plochu.

## Statistiky

Apka posílá anonymní statistiky hraní (které obrazovky a funkce se používají, postup v %, země a město podle připojení). Neukládá jména ani IP adresy, jen náhodné ID zařízení v prohlížeči.
